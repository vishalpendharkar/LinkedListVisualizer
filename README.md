# LinkedListVisualizer

An interactive web application for learning and visualizing Linked List data structures.

## About the Project

LinkedListVisualizer is designed to help students understand how linked lists work through interactive visual representations. Users can perform different linked list operations and observe how nodes and pointers change.

## Technologies Used

### Frontend

* React.js
* Vite
* JavaScript
* Tailwind CSS
* Lucide React
* React Router

### Backend

* Java
* Spring Boot
* Maven

## Features

* Interactive Dashboard
* Singly Linked List visualization
* Doubly Linked List visualization
* Circular Singly Linked List visualization
* Insert nodes
* Delete nodes
* Search for nodes
* Reset the linked list
* Visual representation of nodes and connections

## How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/vishalpendharkar/LinkedListVisualizer.git
```

### 2. Run the Frontend

```bash
cd LinkedListVisualizer/frontend/linked-list-frontend
npm install
npm run dev
```

### 3. Run the Backend

Open another terminal:

```bash
cd LinkedListVisualizer/LinkedListVisualizer
```

Run using Maven:

```bash
mvn spring-boot:run
```

Make sure Java and Maven are installed.
